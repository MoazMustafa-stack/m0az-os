# Security policy

M0AZ_OS is a static portfolio application. Please report security concerns through
the repository's private vulnerability-reporting feature after the public repository
is created. Do not include exploit details in a public issue.

The simulated terminal does not execute local commands or accept server-side input.
If a future contribution adds a backend, dynamic content, analytics, or third-party
integration, document its data boundary and threat model before merging it.
